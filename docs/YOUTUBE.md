# YouTube description

A drone can be ready while the job is not.

GroundProof connects drone inspection jobs to the exact evidence behind their internal approvals. When a notice changes or a source fails, the affected jobs need a fresh human decision.

Try the app: https://groundproof-flight.web.app
Source code and technical documentation: https://github.com/shi1720/HTCJ
Project: https://devpost.com/software/groundproof

In this demonstration:

The six jobs and site-closure drills are fictional and labeled in the product. The $4,800 shown is illustrative planned job value of affected work, not claimed savings. The Boston page is genuinely retrieved through Anakin during recording. GroundProof manages internal evidence decisions; it does not issue flight permission or replace the remote pilot's decisions.

Built by Shivam Gupta with AI-assisted development and testing for the HTCJ × PROOF Aviation Futures Challenge. This video uses an AI-generated narrator from OpenAI text to speech. It is not a voice clone. Screen footage shows the working application.

Our next step is one drone inspection operator for a four-week shadow pilot. We want to measure total review effort, useful alerts, record-maintenance time, and willingness to pay for the proposed $199 monthly workspace price.
