# GroundProof implementation contract
React Vite frontend (root), Fastify SQLite server (backend agent), source capture/evidence rules pure modules (research_rules agent).
Canonical shared types: shared/types.ts (ask root before changing).

All JSON requests same-origin, responses JSON; errors {error:string}. Authorization tenant scoped; httpOnly session. Auth register fields {name,email,password,workspace}; login {email,password}; POST /api/auth/logout; GET /api/auth/me returns {user}; POST /api/demo/start returns {user}. Register creates blank workspace; demo creates isolated seeded workspace. POST /api/demo/reset resets only demo workspace.
GET /api/state -> AppState (no wrapper)
POST /api/sites {name,address,lat,lon} -> Site
POST /api/sources {title,url,category,siteId:null|string,freshnessHours} -> EvidenceSource; POST /api/sources/:id/capture {provider:'direct'|'anakin'} -> EvidenceSource. On failure preserve prior snapshot, record lastError and return 502 {error}. Sources supported initially HTTPS approved public government domains only, manual fixtures only in demos.
POST /api/sources/:id/review {expectedHash,decision:'accepted'|'blocked',note} -> source. Reject stale expectedHash 409, require note >= 8 chars. Reviewing evidence never approves a mission automatically.
POST /api/missions {name,client,siteId,scheduledAt,value,sourceIds} -> Mission; require at least 1 source. Source+site references tenant checked.
POST /api/missions/:id/approve {expectedHashes:Record<sourceId,hash>,note} -> Mission. Reject all stale/blocked/unreviewed/missing/error evidence; require exact current hashes and required source coverage; approval-bound hashes derived status prevents old approval reviving following change even if source reviewed. Re-approval required.
GET /api/missions/:id/export -> downloadable JSON bundle containing mission, exact referenced snapshots, audit events, safety scope, canonical manifest hash (define verifier).
POST /api/demo/drill {scenario:'closure'|'stale'|'unavailable'|'restore'} mutates only fixture source in session-owned demo workspace, audited; returns AppState. Main demo source is 'Harbor Works access notice', affecting first 3 missions with combined booked value $4,800. Initial dataset 6 missions, 3 sites, 5 sources. All aviation plans fictional Boston-area labels, coordinates illustrative and no flight routes. All operational evidence fixture visibly marked. Real FAA source can be added separately, never implicitly authorizes missions.
POST /api/lab/run -> LabReport generated by pure rule tests, not canned successes.
GET /api/health -> {status:'ok',version:'1.0.0'} no secrets.

Derived assessments: held on missing, stale, blocked or unavailable; review on unreviewed/changed or invalidated bound approval; ready only if current source reviews AND exact matching approval; draft if valid source reviews and no approval. Future/invalid timestamps rejected. Freshness measured against current time; server authoritative. ANY content change conservative human review. Direct and Anakin captured text untrusted plain text. No LLM needed for safety or readiness.

No flight authorization, airspace feed, real flights, FAA approval, customer validation or commercial revenue claims. Production is operational evidence management, remote pilot retains all flight responsibilities. Demo is deterministic simulation and fixture injection explicit.
